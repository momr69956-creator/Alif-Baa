# Alif Baa

Arabic vocabulary decks, organized by unit. Each lesson is a self-contained page with its audio embedded.

| Unit | Lesson | Folder |
|---|---|---|
| 8 | New Vocab | [`unit-08/new-vocab/`](unit-08/new-vocab/) |

## Adding a lesson

1. Put the lesson's `index.html` in `unit-NN/<lesson-name>/`.
2. Add a line to the `LESSONS` list in the root `index.html` and a row to the table above.
