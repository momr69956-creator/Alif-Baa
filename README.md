## Adding a page

1. Put the page's `index.html` in `unit-NN/<page-name>/` or `lesson-NN/<page-name>/` (e.g. `lesson-01/exercise-08/`).
2. Add a line to the `LESSONS` list in the root `index.html` (with `unit:` or `lesson:`) and a row to the table above.
